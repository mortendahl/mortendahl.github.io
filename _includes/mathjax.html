{% comment %} Included only on pages with `math: true` in their front matter. The MathJax settings live in the JSON block below so that both ways of rendering use the same ones: - by default (`make serve`, and GitHub Pages' own build) MathJax renders the math in the browser; - with `make build`, which sets `prerender_math` via _config.prerender.yml, `_scripts/prerender-math.js` renders the math into the page as HTML and CSS and removes this block, so readers don't run MathJax. Both use MathJax's CHTML output with the same two adjustments: - math inside handwritten figures (class "hw") is drawn in the handwriting font, by js/handwritten-math.js; - text in math (\text{...}) takes the surrounding font and its natural width, measured by the browser. {% endcomment %} {% unless site.prerender_math %} {% endunless %}
